# Учебный планировщик

Учебный Django-проект для СРС № 5 и СРС № 6. Используются Django Templates, SQLite, Tabler через CDN, JavaScript `fetch()` и Django REST Framework.

## Запуск в Windows CMD

```bat
py -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py test
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. При первом запуске создайте аккаунт на странице регистрации. Для входа используется имя пользователя и пароль.

## Страницы

- `/accounts/register/` — регистрация
- `/accounts/login/` — вход
- `/` — главная панель со статистикой и процентом выполнения
- `/tasks/` — список заданий, поиск, фильтрация, изменение статуса и редактирование
- `/subjects/` — список дисциплин
- `/api-console/` — интерактивный интерфейс управления через REST API
- `/api/subjects/` — CRUD для дисциплин
- `/api/tasks/` — CRUD для заданий

## Аккаунты и доступ

Каждый пользователь видит и изменяет только собственные дисциплины и задания. REST API требует авторизации. Для новых записей владелец задаётся на сервере. Старые записи без владельца при первом входе или регистрации передаются первому аккаунту, который откроет приложение после обновления.

## Проверка названия задания

Название должно содержать не менее двух символов. Разрешены буквы, цифры, пробелы и распространённая пунктуация, например `ЛР2`, `Практика 1` или `ЛР №2 (часть 1)`. Символы вроде `^`, `%`, `$`, `@` и `_` запрещены. Проверка выполняется и в обычной форме, и в REST API.

## REST API

Для обеих сущностей доступны `GET` (список и отдельная запись), `POST` (создание), `PUT`/`PATCH` (изменение) и `DELETE` (удаление). Ответы передаются в формате JSON.

Для `/api/tasks/` доступны серверные параметры фильтрации:

- `search` — поиск по названию задания, например `?search=лабораторная`
- `status` — статус: `new`, `in_progress` или `completed`
- `subject` — ID дисциплины
- `due_after` — срок не раньше указанной даты в формате `ГГГГ-ММ-ДД`
- `due_before` — срок не позже указанной даты в формате `ГГГГ-ММ-ДД`
- `ordering` — сортировка: `due_date`, `-due_date`, `title`, `-title`, `status`

Пример комбинированного запроса: `/api/tasks/?status=in_progress&subject=1&due_before=2026-12-31&ordering=due_date`. Параметры фильтрации применяются на сервере к QuerySet Django ORM.

При удалении дисциплины, к которой привязаны задания, API возвращает ошибку, потому что связь `Task` с `Subject` настроена с `on_delete=PROTECT`.

Tabler загружается через CDN, поэтому для оформления интерфейса требуется интернет-соединение.
